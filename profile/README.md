## {정}말 [축하]! 다니립드???

> (YOU)는 "달러물림"의 세계로 오셨습니!다.
>
> USD/KRW 환율 감지 완료.
> 달러 보유자 및 구경꾼의 접속을 환영합니ㄷr.

**달러물림**은 USD/KRW 환율을 보며 다른 사람들과 실시간으로 떠드는
달러 환율 community입니다.

환율이 오르면 소리 지르고,
내리면 **더 크게** 소리 지르면 됩니다.
(그래야지 사람 산다는걸 알수있죠!)

복잡한 투자 플랫폼보다는,

**"지금 달러 보고 있는 {사람들은} 무슨 생각을 하고 있을까?"**

에서 start했습니다.

## [SYSTEM] 주요 기능

### [RATE_MONITOR]

현재 USD/KRW 환율과 변동을 check할 수 있습니다.

- 현재 USD/KRW 환율
- 기간별 환율 차트
- 시장 상태 및 데이터 기준 시각 표시

무려 [5분만에] 바뀐다고요???

### [CHAT_0001]

하나의 USD방에서 실시간으로 이야기합니다.

- WebSocket 기반 실시간 채팅
- 비회원 채팅 열람
- 회원 메시지 작성
- 네트워크 단절 시 자동 재연결
- 신고 및 사용자 차단

환율 얘기든,
물린 얘기든,
안 물렸다고 자랑하는 얘기든 알@아@서 하시면 됩니다.

### [POSITION.LOG]

보유 달러와 평균 매수 환율을 선택적으로 기록할 수 있습니다.

입력한 포지션을 기준으로 손익률을 계산하고,
채팅에서도 다른 사용자와 현재 상태를 공유할 수 있습니다.

포지션 정보는 사용자가 {직접} 입력합니다.

구라를 치셔도 됩ㄴㅣ 다! 어짜피 알믿을거 ?알잖아요?

### [GUEST_MODE]

계정이 없어도 들어올 수 있습니다.

비회원은:

- 환율 확인
- 차트 확인
- USD방 채팅 열람

이 가능합니다.

메시지 작성 및 개인 기능을 사용하려면 회원가입이 필요합니다.
|눈|팅| 정도면 즐길 권리이죠

### [COSMETIC_SYSTEM]

닉네임을 조금 이상하게 만들 수 있습니다.

- 이름 색상
- 이름 폰트
- 이름 배경
- 장식 뽑기
- 보유 장식 장착 및 변경

중복 장식 획득 시 희귀도에 따라 **달러칩**을 획득하며,
달러칩을 모아 추가 뽑기권으로 교환할 수 있습니다.

!평단은 못 바꿔도 분위기는 바꿀수 있잖아요!

## [MODERATION]
달러물림은 거친 표현 자체를 {과도하게 검열하는 것}을 목표로 하지 않습니다.
