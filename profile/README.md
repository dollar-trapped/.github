# 달러물림

> **물려도, 혼자는 아니니까.**
>
> USD/KRW 환율이 움직이는 순간, 같은 포지션의 사람들과 이야기하는 실시간 환율 커뮤니티

---

## 달러물림은

달러를 들고 있는 사람들이 환율 흐름을 함께 보고, 자신의 생각과 포지션을 편하게 나눌 수 있는 공간입니다.
복잡한 자산 관리보다 **환율이 움직이는 순간 사람들이 모여 이야기하는 경험**에 집중합니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| **실시간 USD/KRW 환율** | 현재 환율과 변동률, 기간별 환율 흐름을 확인합니다. |
| **실시간 채팅** | USD/KRW를 주제로 한 채팅방에서 다른 사용자와 바로 대화합니다. |
| **달러 포지션** | 보유 달러와 평균 매수 환율을 선택적으로 등록하고, 현재 환율 기준 손익률을 표시합니다. |
| **비회원 둘러보기** | 로그인 없이 환율과 차트를 확인하고 채팅을 열람할 수 있습니다. |

## 우리가 검증하는 것

> USD/KRW 환율이 크게 움직일 때, 사람들이 이곳에 모여 대화하는가?

달러물림 v0.1은 하나의 통화, 하나의 커뮤니티에 집중합니다.
채팅 참여와 포지션 등록은 로그인 후 이용할 수 있습니다.

## 프로젝트 구성

| 영역 | 기술 | 역할 |
| --- | --- | --- |
| **App** | Flutter, Dart | 모바일 클라이언트 |
| **Web** | Next.js, TypeScript | 웹 인터페이스 |
| **Server** | Java, REST API, WebSocket | API 및 실시간 서비스 |

## 진행 상태

**MVP v0.1 개발 중**
