# [달러물림]

## {정}말 [축하]! 다니립드???

> (YOU)는 |휼|륭| 한 SerVer 이@시@군@요.
>
> USD/KRW 환율 변동 감지 완료. 달러 보유자 접속을 환영합니ㄷr.

달러물림은 환율을 보며 같은 포지션의 사람들과 떠드는 실시간 커뮤니티입니다.
환율이 오르면 소리 지르고, 내리면 더 크게 소리 지를 수 있습니ㄷr.

---

## [SYSTEM] 접속 가능한 기능

- **[RATE_MONITOR]** 현재 USD/KRW 환율과 변동률을 확인합니ㄷr.
- **[CHAT_0001]** 달러 얘기, 환율 얘기, 물린 얘기를 실시간으로 나눕니ㄷr.
- **[POSITION.LOG]** 보유 달러와 평균 매수 환율을 선택적으로 기록할 수 있습니ㄷr.
- **[GUEST_MODE]** 로그인 없이 환율과 채팅을 구경할 수 있습니ㄷr.

## [NOTICE]

> 환율 급등락이 감지되면 이 서버의 모든 사용자가 동시에 심리적으로 흔들릴 수 있습니ㄷr.
> 달러물림의 포지션 정보는 사용자가 직접 입력한 참고 정보이며, 실제 금융자산을 인증하거나 보증하지 않습니ㄷr.
